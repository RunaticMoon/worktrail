# 업무 흐름 UX 명세 (UXFL-E55A, 2026-10-05)

목표: 기록 → 재검색 → 보고서 작성에서 사용자가 생각·조작할 양을 줄인다. 기존 제품 요구사항(`docs/mac_worklog_ai_handoff/02_PRODUCT_SPEC.md`)과 코드가 우선이며 기능은 삭제하지 않는다. 자주 쓰는 행동은 먼저 보이고, 복잡한 선택은 필요한 순간에만 펼친다.

이 문서는 화면 구조·주요 행동·키보드 규칙·상태 문구의 계약이다. 미정이던 세부는 아래 "기본값과 이유"에 기록했다.

## 1. 핵심 여정과 목표 단계 수

| 여정 | 목표 흐름 | 키 입력 최소 경로 |
|---|---|---|
| ① 다른 앱에서 Memo | 입력 핫키 → (본문에 커서) 입력 → ⌘Return → 이전 앱으로 복귀 | 핫키, 타이핑, ⌘Return |
| ② 원문/Secret 찾기 | 검색 핫키 → 입력(즉시 로컬 결과) → ↑↓ → Space 미리보기 / Return 원문 열기. Secret은 ⌘2(Secret 범위) → 제목 → Return(필요 시 인증) → key 행 ↑↓ → Return 복사 | 핫키, 타이핑, ↓, Return |
| ③ 월요일 주간보고 | 주간보고 열기 → 초안이 이미 보임(지난주 기간) → 오른쪽 "이번 주 계획 후보" 체크 → 확정 → 본문 인라인 수정 → 보고서 복사 | 사이드바, 체크, ⌘S, ⇧⌘C |

## 2. 정보 구조(사이드바)

주요(위): **오늘** · **업무** · **프로젝트** · **주간보고**(팀 제출용) · **성과자료**(성과평가용 상세 기록) · **Secret**
보조(아래, 작은 행): 검색 · 관계 그래프 · 휴지통 · 백업 · 설정

- 주간보고와 성과자료는 서로 다른 사이드바 항목이며, 화면 헤더에 목적 부제를 항상 표시한다. "Weekly" 같은 공통 이름을 쓰지 않는다.
- 기존 "계획" 화면 기능은 주간보고 작업 화면의 "이번 주 계획" 영역으로 들어간다(기능 유지, 출발점 통합).
- 휴지통: 현재 데이터 모델에서 휴지통을 갖는 것은 Secret이다. 휴지통 화면은 Secret 휴지통(복원·영구 삭제)을 보여주고, 일반 기록은 삭제 기능이 없어 휴지통 대상이 아니라고 안내한다.
- 사이드바는 접을 수 있다(⌃⌘S). 접힌 상태에서도 아이콘+툴팁+VoiceOver 라벨을 유지한다.
- 상세(메모·업무·원문)는 sheet로 열고, 닫을 때 원래 화면의 날짜·검색어·필터·선택·스크롤을 복원한다. 추가 상세 패널을 항상 열어 4~5열로 나누지 않는다.

## 3. 화면별 명세

### 3.1 빠른 입력 패널
처음 보이는 것: 유형 세그먼트(Memo/Task/Secret) · 작은 업무일 표시 · 메모 본문(커서) 또는 업무 검색(커서) · `@ 프로젝트` / `# 태그` 버튼 · 저장(⌘Return).

- 열 때 설정의 기본 유형(기본 Memo)으로 시작한다. 유형별 초안·선택·날짜는 보존하며, 초안이 남은 유형에는 작은 점과 접근성 라벨 “초안 있음”을 표시한다. 일반 초안 여부는 `CaptureSessionModel.hasDraft(_:)`, Secret은 `SecretsModel.hasUnsavedRows`를 사용한다. 기본 유형 재설정은 Core 세션의 책임이다.
- 업무일: 오늘이면 작은 보조 텍스트, 과거면 “과거 날짜” 배지 + 시계 아이콘 + “오늘로” 버튼. ⌘D 또는 날짜 변경 버튼으로 날짜 입력을 연다. YYYY-MM-DD 입력, ↑/↓ 하루 증가/감소, T 오늘, Return 확정, Esc 취소(열기 전 날짜 복원). 저장 성공 후 다음 새 기록은 오늘이며 초안의 날짜는 Esc 후에도 유지된다.
- `@`/`#` 자동완성: 공백·줄 시작 뒤에서만 열린다(이메일 `a@b.com`은 열리지 않음). ↑↓ 이동, Return/Tab 선택, Esc 후보만 닫기. 기존 일치 후보만 기본 강조하며 “새로 만들기”는 명시적으로 ↓ 또는 클릭으로 선택한다. 후보 선택이 성립하지 않으면 Return은 줄바꿈이다.
- 프로젝트·태그 버튼: Tab으로 도달하며 ⌘⇧P/⌘⇧T로 검색 피커를 연다. 입력 → ↑↓ → Return 선택, Esc 닫기 → 본문 복귀. 선택 후 본문 문법을 삽입하지 않으며 연결 제거 버튼도 Tab으로 도달한다. 기존 업무 진행 기록은 연결된 프로젝트만 선택하고 태그·새 항목 생성은 제공하지 않는다.
- 업무는 01 업무 검색/목록 → 02 동작 선택 → 03 내용/저장 순서다. 기본 동작은 새 업무 “내용 입력”, 기존 업무 “진행 기록 추가”. 검색 결과가 없어도 새 업무 만들기를 선택하고 이름만으로 저장할 수 있다. 넓은 폭(콘텐츠 ≥880pt)은 세 열, 좁은 폭은 같은 순서의 세로 스크롤이다. 본문 하단 펼침 제목은 줄바꿈하고 스크롤 내부 여백을 둔다.
- 02 열의 “등록 상태”/“상태 변경”은 항상 보이는 라디오 방식 목록(예정·진행·보류·완료·취소)이다. 새 업무의 “완료한 일로 등록”은 `registersAsCompleted == (initialStatus == .completed)`이므로 별도 토글을 제거하고 “완료” 행으로 통합한다. 체크 표시·접근성 선택 라벨·은은한 배경으로 선택을 표시하며 상태 행에 이동 chevron을 쓰지 않는다.
- 동작 목록 ↑↓는 포커스만 이동하고 Space/Return으로 선택한다. →는 선택 후 03으로, ←는 01로 돌아간다. 기존 업무의 불가능한 전이는 “변경 불가”로 설명하고 선택·저장하지 않는다. 상태 변경 시 03에는 저장 안내/완료 확인이 나타나며, 본문을 쓰려면 진행 기록 추가를 선택한다. 완료 시 남은 체크리스트/프로젝트 확인과 취소 경로는 유지한다.
- ⌥1/2/3/4/5는 각각 예정/진행/보류/완료/취소를 즉시 선택한다. 본문에서 눌러도 문자가 삽입되지 않는다. 본문 → 02 복귀는 ⇧Tab 또는 ⌘←. 본문 Return은 줄바꿈, ⌘Return은 저장이다.
- Tab/⇧Tab은 패널 내부 포커스 이동이다. 업무 주요 순서: 날짜 → 01 검색 → 업무 목록 → 02 동작·상태 → 03 본문 → @프로젝트 → #태그 → 관련 기록 → 프로젝트별 상태 관리 → 저장. 연결 제거·확인·오류 재시도 버튼은 해당 영역에 포함한다. 닫기·유형 버튼은 주 흐름 다음에도 Tab으로 도달한다. Secret 편집은 기존 네이티브 필드 순서를 사용한다.
- 유형 전환은 ⌘1/⌘2/⌘3 또는 ⌃Tab/⌃⇧Tab이며 초안을 유지한다. 한글 조합 중(marked text)은 모든 사용자 정의 키를 입력기에 전달한다. 자동완성의 Return/Tab/Esc가 일반 필드 이동·패널 닫기보다 우선한다. 날짜·토큰 피커가 열리면 그 안의 네이티브 키 흐름을 사용한다.
- “관련 기록”/“프로젝트별 상태 관리” 헤더는 Tab 도달, Space/Return 펼침·접힘. 내부 검색·행은 ↑↓ 이동, Space/Return 선택·해제. 관련 기록은 일반 로컬 기록만 검색하고 선택된 연결은 검색어가 바뀌어도 유지한다.
- 저장은 로컬 작업만 기다리고 중복 실행을 막는다. 성공 → 패널 닫고 이전 앱 복귀. 실패 → 입력 보존 + “저장하지 못했습니다 · 입력은 그대로 있습니다 · [다시 저장]”. 저장 중 주요 컨트롤은 비활성화한다. Esc는 자동완성/피커를 닫은 다음 패널을 닫으며 초안을 보존한다.

빠른 입력 요소별 키 계약(실제 Mac 조작 검증 전):

| 요소 | Tab / ⇧Tab | 화살표 | Return / Space | 단축키 |
|---|---|---|---|---|
| 날짜 변경 / 오늘로 | 도달 | 날짜 입력 ↑↓ 하루 | 날짜 확정 / 버튼 실행 | ⌘D, 날짜 입력 T, Esc 취소 |
| 01 업무 검색 | 도달 | ↑↓ 업무 강조, 텍스트 끝 → 02 | 업무 선택 후 02 / 공백 입력 | ⌘2 업무 유형 |
| 업무 목록 | 모든 행 도달 | ↑↓ 이동, ← 검색, → 02 | 선택 후 02 | — |
| 02 동작 / 상태 | 모든 행 도달 | ↑↓ 포커스, ← 01, → 03 | 선택 | ⌥1–5 상태 |
| 03 본문 | 도달, ⇧Tab으로 02 | 네이티브 캐럿 이동 | 줄바꿈 / 공백 | ⌘← 02, ⌘Return 저장 |
| @프로젝트 / #태그 | 도달 | 피커 ↑↓ 후보 | 피커 선택 / 버튼 열기 | ⌘⇧P / ⌘⇧T, Esc 피커 닫기 |
| 연결 제거 버튼 | 도달 | — | 제거 | — |
| 관련 기록 펼침 / 내부 행 | 도달 | ↑↓ 검색·행 이동 | 펼침·접힘 / 연결·해제 | — |
| 프로젝트별 상태 관리 / 토글 | 도달 | ↓ 내부, ↑ 헤더 | 펼침·접힘 / 추적 방식 전환 | — |
| 저장 / 재시도 / 완료 확인 | 활성 컨트롤 도달 | — | 실행 | ⌘Return 저장 |
| 닫기 / 유형 버튼 | 주 흐름 뒤 도달 | — | 실행 | Esc, ⌘1–3, ⌃Tab/⌃⇧Tab |

Mac 확인 절차(가짜 테스트 기록만):
1. macOS 14+에서 R의 `hasDraft(_:)` 계약을 통합하고 앱 타입 검사·빌드. 기본 메모 → ⌘2 → 검색 → Return → ↑↓ → Space/Return → → → 본문 → ⇧Tab/⌘← → 본문 → ⌘Return 저장을 마우스 없이 실행한다.
2. 본문 편집 중 ⌥1–5를 각각 눌러 문자 삽입 없이 상태가 바뀌는지 확인한다. 기존 업무에서는 허용 전이/변경 불가/남은 항목 완료 확인/취소를 확인한다.
3. ⌘D → ↑↓ → T → Return, 다시 ⌘D → 과거 날짜 → Esc로 원래 날짜 복원. 잘못된 날짜는 Return·완료 버튼 모두 확정을 막는지 확인한다.
4. 본문 @/# 후보의 ↑↓/Return/Tab/Esc, 버튼 및 ⌘⇧P/T의 피커 입력·선택·닫기, 관련 기록·프로젝트 추적 펼침과 내부 조작을 확인한다.
5. 한글 조합 중 Tab/Return/Esc/⌥숫자/⌘←/⌘Return이 입력기를 우선하는지, 반복 ⌘Return이 중복 저장하지 않는지 확인한다. Secret은 잠금·인증·초안 선택·제목/행 Tab 이동·저장을 가짜 값으로 확인한다.
6. 패널 최소 폭/높이, 880pt 전후 크기 변경, 밝은/어두운 모드, 대비 높이기, 키보드 탐색 설정 켜짐/꺼짐에서 모든 포커스 링·자동 스크롤·긴 펼침 제목을 확인한다. VoiceOver로 선택/초안/펼침/변경 불가 라벨을 확인한다.
7. 일반/Secret 초안을 각각 남기고 Esc 후 재열기: 기본 유형과 초안 점·날짜 보존 확인. 테스트 저장 실패 상황에서 입력 보존·Tab 재시도를 확인한다.

### 3.2 오늘(날짜 화면)
- 헤더: 날짜 선택(◀ 날짜 ▶, 오늘) + 과거 날짜면 "해당 날짜 종료 기준" 배지(아이콘+라벨)와 한 줄 설명 "이 화면의 업무 상태는 그날 종료 시점 기준입니다. 현재 상태는 업무 화면에서 관리합니다."
- 넓은 창(≥ 980pt): 타임라인 / 업무 / 메모 정리 3열.
- 좁은 창: 세그먼트 "타임라인 n · 업무 n · 메모 n"으로 한 영역씩 전환. 선택한 영역·선택 항목은 배치가 바뀌어도 유지. 글자 크기를 줄이지 않는다.
- 빈 상태: "이 날짜의 기록이 없습니다 · [기록 추가 ⌘N]".

### 3.3 업무 / 업무 상세
- 목록 행: 업무명 · 전체 상태 배지(아이콘+라벨) · 프로젝트 이름(최대 2개 + "외 n") · 마감(있을 때만, 지난 마감은 "마감 지남" 라벨).
- 상세: 위에 업무명·전체 상태·[진행 기록 추가]·[Task 전체 완료]. 아래 펼침 섹션: 프로젝트별 적용 상태(기본 펼침이 아님, 요약 "G 완료 · J 진행 · K 예정" 표시) · 체크리스트("체크리스트 2/3", 퍼센트·"완료율" 표현 금지) · 진행 기록 · 근거·이력.
- 네 가지 정보를 섞지 않는다: Task 전체 상태 / 프로젝트별 상태 / 체크리스트 완료 여부 / 이번 주 계획 포함 여부(별도 "이번 주 계획" 칩).
- 버튼 이름: 프로젝트 행 "G에 적용 완료"(해당 프로젝트만) vs 헤더 "Task 전체 완료". 체크리스트를 모두 완료해도 자동 완료하지 않는다. 남은 항목이 있으면 한 번의 확인 시트에 남은 체크리스트·프로젝트 범위를 보여준다(연속 확인창 금지).
- 진행 기록 입력에 범위 선택: "공통"(기본) 또는 연결된 프로젝트 중 하나. 목록에서 범위 라벨을 표시.
- 계획 포함은 상태·시작일을 바꾸지 않는다. 같은 Task를 날짜·프로젝트별로 복제하지 않는다.

### 3.4 프로젝트
- 프로젝트 목록(이름, 진행 중 업무 수) → 선택 시 해당 프로젝트에 연결된 업무와 그 프로젝트 기준 상태(전체 상태와 별도 열)를 보여준다. 업무를 열면 업무 상세.

### 3.5 검색(패널·메인 공통)
- 검색 입력 하나와 범위 세그먼트 **전체(기본)** / **기록** / **Secret**. 검색 패널에서만 ⌘1=전체 / ⌘2=기록 / ⌘3=Secret을 처리한다. 메인 검색 화면의 ⌘1~6은 전역 화면 이동이며 범위는 클릭 또는 Tab 포커스 후 화살표로 전환한다.
- 전체는 한 목록에 기록 섹션과 Secret 섹션을 보여 준다. Secret은 SecretsModel의 로컬 제목 검색만 사용하며 제목·그룹명만 표시한다. 값·key는 결과 행에 표시하지 않고, 빈 Secret 섹션은 숨긴다. 잠금 중 행 부제는 “잠김 · Return으로 잠금 해제”.
- 입력 즉시 로컬 결과(150ms 디바운스). 기록 필터(유형·기간·프로젝트·태그)는 “필터” 버튼으로 펼치며 Secret에는 적용하지 않는다. 기록 행은 유형·업무일·프로젝트·일치 문맥을 표시한다.
- ↑↓는 섹션 경계를 넘어 선택만 이동한다. 기록 Return은 원문 sheet, Secret Return은 필요한 경우 기기 인증 한 번 → key 목록 → 첫 key 자동 선택 → 다시 Return 값 복사(값 미표시 피드백). key 목록에서 ↑↓ 선택, Esc/⌘←는 검색어·선택을 유지해 결과로 복귀한다. 편집 중이거나 복구할 Secret 초안은 덮어쓰지 않고 기존 화면에서 정리하도록 안내한다.
- Space는 포커스된 기록 결과 미리보기, 입력 중 Space는 공백 입력(⌥Space는 기록 미리보기). 결과가 갱신돼도 같은 id가 남아 있으면 선택을 유지하고 사라질 때만 해제한다.
- ⌘Return/AI 버튼은 선택이 기록 또는 없음일 때만 명시 실행한다. Secret 선택 시 비활성화하고 “Secret은 AI로 보내지 않습니다”를 표시한다. AI 입력은 사용자가 직접 입력한 질문과 기록 근거뿐이며 Secret 결과·제목·선택·key·값을 전달하지 않는다. Secret 결과는 App 계층에만 유지하며 SearchModel/SearchIndex에 넣지 않는다.
- 원문 sheet 또는 key 목록에서 돌아오면 검색어·필터·선택을 유지한다. 패널을 닫았다 열어도 같은 세션 상태를 재사용한다. 이미 보이는 패널에 검색 핫키를 누르면 앞으로 가져오고 검색 입력에 포커스·전체 선택한다. 빠른 입력 패널이 열려 있어도 초안은 보존한다.
- 메뉴바 “검색 열기 (현재 단축키)”로 패널 표시를 직접 확인할 수 있다. 설정 > 단축키 및 메뉴바에 등록됨/등록 실패(OSStatus 포함)와 최근 눌림 HH:mm:ss를 표시한다. 수신 시각은 주입 Clock과 업무 시간대를 사용하며 실행 중 메모리에만 보관하고 로그 파일에 남기지 않는다. 메뉴로 열리지만 핫키 최근 눌림이 갱신되지 않으면 등록/충돌/키 수신을, 갱신됐으나 패널이 안 보이면 표시/활성화 경로를 확인한다.

### 3.6 주간보고(팀 제출용)
- 헤더: "주간보고 · 팀 제출용" + 기간 두 줄 "지난주 실적 9월 28일(월) ~ 10월 4일(일) · 일요일 종료 기준" / "이번 주 계획 10월 5일(월) ~ 10월 11일(일)". 양식: "제출용 주간보고 v3 · 양식 관리".
- 진입 시 그 주 리포트가 없으면 AI 없이 기록 기반 초안을 즉시 만들어 보여준다(마법사 없음). AI 초안은 사용자가 "AI로 다시 쓰기"를 눌렀을 때만.
- 한 작업 화면: 왼쪽 보고 초안(인라인 편집) · 오른쪽 "이번 주 계획 후보"(체크 → [선택 항목 확정]; 확정 전에는 "후보" 라벨) · 아래 "성과 보충 질문"(한 장씩, 답변/결과 없음/나중에/제외, "n개 남음", 건너뛰어도 복사·확정 가능).
- 공통 업무는 "공통" 묶음 아래 한 번만. 짧은 보고 본문과 상세 성과 근거(펼침)는 구분.
- [보고서 복사](⇧⌘C): "클립보드에 복사했습니다 · 제출 상태는 바뀌지 않습니다". [확정]: "확정본 v4 · 이후 수정은 새 버전". 복사만으로 "제출 완료"를 표시하지 않는다.
- 재생성: 현재 버전이 수정본·확정본이면 새 버전을 만들어도 화면은 현재 본문을 유지하고 "새 초안 v5가 준비됨 · [변경 비교] [새 초안 적용] [닫기]"를 보여준다. 변경 비교는 줄 단위 추가/삭제 표시.

### 3.7 성과자료(성과평가용 상세 기록)
- 헤더 "성과자료 · 성과평가용 상세 기록". 기간 유형·평가 기간 선택, 초안/확정본은 기존 동작 유지. 같은 재생성 보호 적용.

### 3.8 Secret
- 조회(기본): 제목 검색 → (잠김이면 [잠금 해제] 한 번) → key 목록(값 가림). 행 클릭 또는 Return = 값 복사. ↑↓는 포커스만. "보기" 버튼(눈 아이콘)으로만 값 표시. 복사 피드백 "‘key’ 값을 복사했습니다 · 120초 후 클립보드 비움"(값 미표시).
- 편집: [편집]을 눌러야 key/value 표가 편집 가능. 셀 선택 = 수정. Tab/⇧Tab 셀 이동, 행 추가·삭제, `A=B`·`A : B` 붙여넣기 미리보기. key 없으면 key1/key2. trim은 저장 시 앞뒤만. 중복 key는 해당 행에 인라인 경고하고 저장하지 않음. 가림 문자(•)만으로 된 값은 저장을 막고 인라인 경고. [저장](⌘S)·[취소].
- 가림 상태의 값은 화면·툴팁·접근성 값으로 노출하지 않는다(접근성 라벨 "가려진 값").
- 버전·휴지통·잠금·암호화는 기존 동작 유지.

### 3.9 설정
- 일반: 기본 입력 유형. 단축키: 입력·검색 핫키 레코더 + 등록 실패/충돌 설명 + 앱 내 단축키 목록. AI·스킬: 연결 상태(연결됨/미연결/오프라인/실패) + "나중에 연결해도 기록·검색은 바로 사용할 수 있습니다". 백업: 위치(홈 하위), 마지막 성공 시각, [지금 백업] [복원…] → 백업 화면.

## 4. 키보드 규칙(공통)

| 키 | 동작 | 예외 |
|---|---|---|
| Return | 텍스트: 줄바꿈 / 목록: 실행(원문 열기·Secret 복사) | IME 조합 중·자동완성 열림 → 입력기/자동완성 우선 |
| ⌘Return | 빠른 입력 저장 / 검색 AI 답변 | 저장 중이면 무시 · Secret 결과/key 선택 시 AI 실행 금지 |
| Esc | 자동완성 닫기 → 시트 닫기 → 검색 Secret key 목록에서 결과 복귀 → 패널 닫기(초안 보존) | IME 조합 중 → 입력기 |
| ↑↓ | 포커스 이동만(복사·열기 아님) | 검색은 기록/Secret 섹션을 넘어 선택 이동 · 한 줄 검색 필드에서 결과 선택, 여러 줄 텍스트 편집은 커서 이동 |
| Space | 검색 결과 미리보기 | 텍스트 필드 포커스 중에는 공백 입력 |
| ⌘1/2/3 (빠른 입력) | 메모·업무·Secret 유형 전환(⌃Tab/⌃⇧Tab도 순환) | 초안 유지 · IME 조합 중에는 입력기 우선 |
| ⌘1/2/3 (검색 패널) | 전체·기록·Secret 범위 전환 | 메인 창의 ⌘1~6은 전역 화면 이동(메인 검색 화면 포함) |
| Tab / ⇧Tab | 빠른 입력 패널의 다음 / 이전 컨트롤 | IME·자동완성 우선; 유형 전환에 사용하지 않음 |
| ⌥1–5 | 빠른 입력 업무의 예정/진행/보류/완료/취소 선택 | IME 조합 중·피커 열림은 입력기/피커 우선; 기존 업무는 허용 전이만 |
| ⌘D | 빠른 입력 날짜 필드 | ↑↓ 하루, T 오늘, Return 확정, Esc 취소 |
| ⌘⇧P / ⌘⇧T | 빠른 입력 프로젝트 / 태그 피커 | 진행 기록은 연결 프로젝트만, 태그 없음 |
| ⌘← (빠른 입력) | 업무 본문에서 02 동작으로 | IME 조합 중은 입력기; ⇧Tab도 복귀 |
| ⌘← (검색) | Secret key 목록에서 검색 결과로 복귀 | 검색어·선택 유지 · IME 조합 중에는 입력기 우선 |
| ⌘C/⌘V/⌘Z | 시스템 표준 편집 | 앱이 가로채지 않음 |

단축키는 메뉴 항목·버튼 툴팁(키캡)·설정 목록에서 발견할 수 있게 한다.

## 5. 상태 문구 매트릭스

| 상태 | 원칙 | 예시 |
|---|---|---|
| 기록 없음 | 다음 행동 버튼 | "이 날짜의 기록이 없습니다 · [기록 추가]" |
| 검색 결과 없음 | 필터·철자 안내, AI 자동 호출 없음 | "‘배포’와 일치하는 원문이 없습니다 · 필터 3개 적용 중 [필터 초기화]" |
| 처리 중 | 진행 표시 + 나머지 화면 사용 가능 | "AI 답변 작성 중… 결과 목록은 계속 볼 수 있습니다" |
| 오프라인 / AI 미연결 | 로컬 기능은 정상임을 알림 | "AI에 연결되어 있지 않습니다 · 기록 기반 초안을 사용합니다 · [설정에서 연결]" |
| 실패 | 무엇이 실패 · 무엇은 저장됨 · 재시도 방법 | "AI 초안 생성 실패 · 기존 본문은 그대로 · [다시 시도]" |

짧게 사라지는 알림만으로 복구를 제공하지 않는다. 실패 문구는 원인이 해결될 때까지 화면에 남고, 되돌리기는 버전 목록·휴지통 같은 다시 접근 가능한 경로를 함께 둔다.

## 6. 시각 규칙
- 시스템 글꼴과 텍스트 스타일(`.body`, `.callout`, `.headline`…)을 사용해 글자 확대 설정을 따른다. 고정 pt는 키캡 등 장식 요소에만.
- 색은 의미 기반 시스템 색(labelColor, secondaryLabelColor, separatorColor, controlAccentColor, windowBackgroundColor 등)을 우선한다. 상태는 색만으로 전달하지 않고 아이콘+라벨을 함께 쓴다(`StatusBadge`).
- 장식 그라데이션·큰 KPI·장식 그래프·상시 챗봇을 넣지 않는다. 필수 액션은 hover·우클릭에만 숨기지 않는다.
- 동작 줄이기·대비 높이기 설정을 존중한다.

## 7. 기본값과 이유
- 기본 입력 유형 Memo: 가장 잦은 행동이며 제목 없이 끝나는 유일한 유형이다.
- "새로 만들기" 후보 기본 미강조: 코드·해시 문자열 뒤 Return이 줄바꿈으로 남아야 본문을 임의로 바꾸지 않는다.
- 과거 날짜 초안은 Esc 후 재열기 시 유지: 초안 보존 요구와 충돌하지 않게 하되, 배지로 드러내고 저장 후에는 오늘로 돌린다.
- 좁은 창 기준 980pt: 3열 각각 최소 300pt + 여백. 그 아래에선 한 영역 전환이 세로 적층보다 스크롤·맥락 손실이 적다.
- 휴지통 = Secret 휴지통: 일반 기록 삭제 기능은 현재 제품 범위에 없다(기능 추가는 별도 결정 필요).
- 주간보고 진입 시 기록 기반 초안 자동 생성: 로컬·결정적이고 기존 편집본을 덮지 않으며, AI 호출은 명시 실행으로 남는다.
- 계획 화면 통합: 월요일 여정이 한 화면에서 끝나도록 하되 후보 생성·확정 기능은 그대로 둔다.
