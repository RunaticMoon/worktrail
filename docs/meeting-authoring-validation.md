# 회의 작성·업무 연결·탐색·독립 처리 검증

2026-10-28 KST, 이슈 #38·#39·#41·#42·#43의 회의 전용 구현 기록이다. #40 아카이브, 전역 검색 진입·업무 역링크·프로젝트 관련 회의와 일반 AI/리포트 보호는 통합 변경에서 별도로 검증한다.

## 변경 동작

- 신규 로컬 회의에서 AI 설정 없이 요약·결정사항·할 일·확인사항을 직접 작성한다. 수동 저장마다 새 버전을 남기며 AI 인용을 복제하지 않는다. 기존 AI 본문 편집은 이전·교체 본문 이력도 남긴다. 전사와 요약은 독립 저장하고 원문 revision이 달라지면 검토 필요로 표시한다.
- 자동 저장 오류·동시 요약 변경 시 입력을 유지한다. 경쟁 저장은 최신 내용을 보여준 뒤 사용자가 새 버전 저장을 선택해야 재시도한다. 배경 새로고침이 입력 중인 요약의 revision을 조용히 갱신하지 않는다.
- 수동 할 일, 메모 및 전사 구간을 업무 검토 카드로 연다. 근거 문장은 선택한 원문 일부만 허용한다. 제목·담당자·기한·프로젝트를 확인하고 확정해야 생성/연결하며 담당·기한은 미지정이 기본이다. 같은 action key를 재확정해도 업무를 중복 생성하지 않는다. 기존 업무 연결은 상태·기한을 바꾸지 않는다.
- 회의·전사 버전·구간 ID와 원문 인용을 별도 출처 테이블에 보존하고 localOnly를 전파한다. 이 화면은 보호를 해제하는 공유 전환 기능을 제공하지 않는다.
- 여러 프로젝트·태그·참석자·안건·선택 실제 시각을 업무일과 구분하여 저장한다. 보관함에 프로젝트/태그/업무일 범위/정렬을 제공한다. 보관되거나 사용할 수 없는 프로젝트 연결은 원문을 삭제하지 않고 표시한다.
- 일반 AI 검색 자료와 다른 로컬 검색 API로 버전·구간까지 찾는다. 전사 화면은 Cmd+F, Cmd+G/Shift+Cmd+G, 검색 강조, 화자·미확인·미확정·수정됨·시간 필터를 제공한다. 검색 결과 진입 시 숨겨진 해당 구간을 표시하도록 필터를 해제하고 전사 영역을 연다.
- 원본 재생은 구간 끝 정지, 일시정지·재개·정지, 배속, ±5초, 위치 탐색을 제공한다. 트랙 시작 오프셋/중단 구간은 기존 타임라인 변환을 사용한다. 다른 회의로 이동하면 이전 음성을 정지한다. 원본이 없으면 텍스트 수정과 누락 안내를 유지한다.
- 정밀 전사만/정밀+화자/저장된 정밀에 화자 분리를 선택한다. 완료된 정밀 결과의 원본 SHA256·타임라인·설정·모델이 일치하고 사용자 수정이 없을 때만 재사용한다. 정밀 전사와 화자 분리 결과는 별도 버전이며 활성 전사를 자동 교체하지 않는다. 처리 초/전체 초/진행률과 취소·실패 단계 안내를 표시하며 ETA를 약속하지 않는다.
- 가져온 아카이브의 원본만 다시 내보내면 선택 녹음의 오디오와 `originals.json`(버전·트랙·누락 ID·localOnly)을 숨겨진 임시 폴더에 준비한 뒤 공개한다. 기존 목적지를 덮어쓰지 않는다. 원본 삭제는 선택 녹음의 DB 트랙 파일만 unlink하고, 같은 import 폴더의 다른 녹음과 전사·폴더를 유지한다. import 폴더는 네이티브 복구 저널 탐색에서 제외하고 DB 경로로 누락을 확인한다. 전체 회의 왕복은 별도의 회의 아카이브 기능을 사용한다.
- 네이티브 녹음과 가져온 아카이브의 DB 상대 경로를 같은 검증기로 연다. 경로 탈출·각 경로 요소의 심볼릭 링크·일반 파일이 아닌 원본은 재생 및 처리 전에 거절한다.

## 자동 검증

- Apple Swift 6.4 / Xcode 27.1 SDK에서 `swift build --build-tests --jobs 4` 성공, deployment target macOS 26.0. 저장소의 Swift 6.3 지침과 실제 실행 도구 버전을 구분한다.
- `swift test --skip-build --filter Meeting`: 77개 통과. 새 수동 요약·메타데이터·출처·검색 테스트 7개를 포함한다.
- `scripts/maclab/run-meeting-session-check.sh`: 네트워크 차단, 가짜 자격증명·PCM·추론으로 실제 앱 소스 15개 suite 통과. 실패한 화자 단계 재시도에서 Whisper 호출/해제 모두 0회, 변경된 설정/원본 SHA256/수정 전사 거절, 정밀만 실행, 단계 취소 보존, 복원 경로 원본의 처리와 AVAudioPlayer 로드, 경로 탈출/심볼릭 링크 거절, 복원 원본 내보내기/덮어쓰기 거부/동일 폴더 다른 녹음 보존/복구 스캔 제외, 실제 MeetingsModel 자동 저장 실패·경쟁 변경·재생성 후 수동 초안 보존을 포함한다. 실제 마이크·모델 다운로드·외부 AI는 사용하지 않는다.
- 6,000구간(5초 간격, 8시간 20분 타임라인) 가짜 fixture: 검색 50건 0.96ms, 전체 구간 로드 46.19ms, 테스트 프로세스 peak RSS 49,266,688bytes. 단일 측정이며 DB 작성 비용을 검색/로드 시간에 포함하지 않는다. RSS는 전체 XCTest 프로세스 최대값으로 앱 화면 메모리 측정이 아니다.

## 실제 macOS 화면 검증

DEBUG `dev.worklog.UIReview` 번들을 `/tmp/WorkLogMeetingReview-*`에서 `--ui-test-fixture many`로 실행했다. 실제 실행 인자와 번들을 검증한 뒤 `meeting-ui-check.js`를 사용했다. 1180×800과 960×640에서 다음 동선이 모두 통과했다.

- 키보드 사이드바 경로로 회의 진입, 새 회의 생성.
- 제목·전사·메모와 수동 4개 섹션의 키보드 입력 및 Cmd+S 저장.
- 화면 이탈 후 돌아와 선택·메모·수동 요약·결정사항 보존.
- 업무 검토 카드 열기, 담당자 미지정 확인, 취소 후 초안 유지.
- 휴지통 이동·복원 후 제목과 메모 보존.

helper는 AX 포커스만으로 편집기가 실제 첫 응답자가 되지 않는 경우 포인터로 편집기를 포커스한다. 긴 화면에서는 외부 ScrollArea를 실제로 스크롤한다. 따라서 위 결과는 키보드 입력·저장과 검증한 이동의 결과이며 전체 동선이 포인터 없이 가능하다는 증명은 아니다. 960×640의 본문 스크롤·수동 섹션 줄바꿈을 스크린샷으로 확인했다. 이후 전사 버전/재생 명령 행은 좁은 화면에서 줄을 나누도록 보완하고 macOS 빌드로 확인했다.

한글 IME 조합 중 입력, VoiceOver 음성 탐색, 실제 장시간 오디오와 한국어 모델의 정확도/속도, 전체 전사 제어의 키보드 단독 동선은 별도 미검증이다. 화면 테스트의 영문 가짜 입력을 한글 IME 검증으로 간주하지 않는다.
