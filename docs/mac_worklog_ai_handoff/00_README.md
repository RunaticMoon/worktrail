# Mac 업무 기록 앱 — AI 개발 인계 패키지

작성일: 2026-10-01 · 버전: 1.0 · 문서 언어: 한국어

> 짧게 기록한 업무를 날짜별 활동, 제출용 주간보고, 상세 성과평가 자료로 연결하는 한 대의 Mac 전용 앱.

## 바로 사용하는 방법

새 프로젝트 저장소에 이 패키지를 `handoff/`로 넣고, 개발 AI에게 `01_AI_BUILD_PROMPT.md` 전체를 첫 메시지로 전달한다. 해당 AI가 파일을 읽을 수 있으면 폴더 경로를 알려주고, 파일을 첨부하는 방식이면 ZIP을 풀어 Markdown 파일을 함께 첨부한다.

가장 간단한 시작 메시지:

```text
첨부한 Mac 업무 기록 앱 개발 인계 문서를 읽어줘.
01_AI_BUILD_PROMPT.md를 실행 지시문으로, 02_PRODUCT_SPEC.md를 제품 요구사항의 기준으로 사용해.
이미 정한 기능을 다시 인터뷰하지 말고, 미정인 세부사항은 문서의 제안 기본값으로 진행해.
기존 저장소를 먼저 확인한 뒤 구현 계획을 짧게 세우고, 실제 코드와 테스트를 단계적으로 작성해.
첫 버전에서 Secret은 AI를 전혀 사용하지 않으며, 제출용 주간보고와 상세 Weekly 리포트는 서로 다른 산출물이라는 점을 특히 지켜줘.
```

파일을 하나만 첨부해야 하는 환경에는 패키지와 함께 제공한 `mac_worklog_ai_handoff_all.md`를 사용한다. 통합본과 분할본은 동일한 내용을 담는다.

## 파일 구성

| 파일 | 목적 |
|---|---|
| `01_AI_BUILD_PROMPT.md` | 개발 AI에게 바로 전달하는 실행 지시문 |
| `02_PRODUCT_SPEC.md` | 인터뷰에서 확정한 제품 요구사항, UX, 상태와 보고 규칙 |
| `03_TECHNICAL_DESIGN.md` | 제안 아키텍처, 데이터 모델, 시간 이력, 보안과 Codex 연결 |
| `04_IMPLEMENTATION_PLAN_AND_TESTS.md` | 단계별 개발 순서, 인수 조건, 회귀 테스트와 완료 기준 |
| `05_RUNTIME_PROMPTS.md` | 앱이 실제로 사용할 보고·질문·연결 제안용 프롬프트 초안 |
| `06_DECISIONS_AND_SOURCES.md` | 최종 결정, 폐기된 방향, 제안 기본값, 공식 기술 참고 자료 |
| `07_EXAMPLE_DATA.json` | 가짜 값으로만 구성한 예시 데이터와 기대 결과 |

## 문서의 권위와 해석

1. 이 패키지 이후 사용자가 명시한 변경사항.
2. `02_PRODUCT_SPEC.md`의 **확정 요구사항**.
3. `06_DECISIONS_AND_SOURCES.md`의 결정 기록.
4. 기술 설계·테스트·런타임 프롬프트.

**확정**은 인터뷰에서 사용자가 결정한 제품 행동이다. **제안 기본값**은 선택되지 않은 구현 세부사항을 진행 가능하게 만든 가정이다. **향후**는 첫 버전의 필수 완료 조건이 아니다. 기술 문서가 제품 요구사항을 몰래 축소하거나 확장해서는 안 된다.

## 반드시 유지할 여섯 가지

- 입력과 검색의 전역 핫키는 다르다. 기본 입력은 Memo이며 설정에서 변경한다.
- Task는 날짜별 복제본이 아닌 전역 원본이다. 날짜별 상태·활동 이력을 별도로 보존한다.
- 여러 프로젝트에 연결된 하나의 Task를 전체 업무 집계에서 중복 계산하지 않는다.
- 제출용 주간보고는 지난주 종료 상태와 이번 주 확정 계획을 간략히 표시한다. 성과용 리포트는 별도다.
- Secret은 표 UI → JSON 구조 → 로컬 암호화 저장이다. Secret용 AI·로컬 LLM·마스킹 전송 단계는 없다.
- 첫 버전에서 외부 링크 내용 수집은 필수가 아니다. 향후에도 Task에 직접 연결한 GitHub PR·Jira 이슈만 읽는다.

## 이 패키지의 범위

이 패키지는 **구현을 맡기기 위한 기획·기술 명세·프롬프트·검증 시나리오**다. 실행 가능한 Mac 앱, Xcode 프로젝트, 실제 계정 연결 또는 완료된 보안 검증 결과가 아니다. 예시 JSON은 테스트 픽스처이며 앱의 확정 저장소 스키마나 실사용 데이터가 아니다.

외부 제품의 권한·요금·프로토콜은 설치 버전과 회사 설정에 따라 달라질 수 있다. 구현 AI는 `06_DECISIONS_AND_SOURCES.md`의 공식 문서를 확인하고, 실제로 확인하지 못한 호환성을 성공했다고 보고하지 않는다.
